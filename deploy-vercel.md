# 🚀 TurtleTrading Vercel Deployment Guide

## Prerequisites

1. **Vercel Account**: Sign up at [vercel.com](https://vercel.com)
2. **Vercel CLI**: Install globally with `npm i -g vercel`
3. **GitHub Repository**: Your repo should be accessible to Vercel
4. **Database Setup**: PostgreSQL database (Vercel Postgres, Supabase, or other)
5. **Redis Setup**: Redis instance (Upstash, RedisLabs, or other)

## 🔧 Step 1: Install Vercel CLI and Login

```bash
# Install Vercel CLI globally
npm install -g vercel

# Login to your Vercel account
vercel login
```

## 🗄️ Step 2: Set Up External Services

### Database Options:
- **Vercel Postgres**: `vercel storage add postgres`
- **Supabase**: Create project at supabase.com
- **PlanetScale**: Create database at planetscale.com

### Redis Options:
- **Upstash**: Create Redis database at upstash.com
- **RedisLabs**: Create instance at redislabs.com

## 🔑 Step 3: Configure Environment Variables

Copy `.env.example.vercel` contents and set these in Vercel dashboard:

```bash
# Essential Variables
DATABASE_URL=postgresql://...
REDIS_URL=redis://...
JWT_SECRET=your-secret-key
GITHUB_PAT=your-github-token

# API URLs (auto-generated by Vercel)
VITE_API_BASE_URL=https://your-app.vercel.app/api
VITE_WS_BASE_URL=wss://your-app.vercel.app/ws
```

## 🚀 Step 4: Deploy to Vercel

### Option A: Deploy via CLI

```bash
# Navigate to project root
cd /Users/kiranreddyghanta/TurtleTrading

# Deploy to Vercel
vercel

# Follow the prompts:
# ? Set up and deploy "~/TurtleTrading"? [Y/n] y
# ? Which scope do you want to deploy to? [Your Team]
# ? Link to existing project? [y/N] n
# ? What's your project's name? turtletrading
# ? In which directory is your code located? ./
```

### Option B: Deploy via GitHub Integration

1. Go to [vercel.com/dashboard](https://vercel.com/dashboard)
2. Click "New Project"
3. Import your GitHub repository: `ghantakiran/turtletrading`
4. Configure build settings:
   - **Framework Preset**: Vite
   - **Root Directory**: `frontend`
   - **Build Command**: `npm run build:vercel`
   - **Output Directory**: `dist`

## ⚙️ Step 5: Configure Build Settings

In Vercel dashboard:

1. **Root Directory**: Leave as `./` (monorepo setup)
2. **Build Command**:
   ```bash
   cd frontend && npm ci && npm run build:vercel
   ```
3. **Output Directory**: `frontend/dist`
4. **Install Command**:
   ```bash
   cd frontend && npm ci
   ```

## 🔄 Step 6: Set Up Environment Variables in Vercel

Navigate to your project settings → Environment Variables:

```bash
# Production Variables
DATABASE_URL=postgresql://username:password@host:5432/database
REDIS_URL=redis://username:password@host:6379
JWT_SECRET=your-super-secret-key-here
GITHUB_PAT=github_pat_your_token_here

# Auto-generated URLs (replace with your domain)
VITE_API_BASE_URL=https://turtletrading.vercel.app/api
VITE_WS_BASE_URL=wss://turtletrading.vercel.app/ws

# Optional API Keys
ALPHA_VANTAGE_API_KEY=your_alpha_vantage_key
NEWS_API_KEY=your_news_api_key
```

## 📡 Step 7: API Route Configuration

The backend FastAPI application will be accessible via:
- **API Routes**: `https://your-app.vercel.app/api/*`
- **Health Check**: `https://your-app.vercel.app/api/health`
- **Interactive Docs**: `https://your-app.vercel.app/api/docs`

## 🧪 Step 8: Test Deployment

```bash
# Test API endpoints
curl https://your-app.vercel.app/api/health

# Test frontend
open https://your-app.vercel.app

# Check logs
vercel logs your-app-url
```

## 📊 Step 9: Performance Optimization

### Enable Analytics:
```bash
vercel analytics enable
```

### Configure Caching:
- Static assets: 1 year
- API responses: Based on endpoint
- Database queries: Redis caching

## 🔍 Troubleshooting

### Common Issues:

1. **Build Fails**: Check build logs in Vercel dashboard
2. **API 500 Errors**: Verify environment variables
3. **Database Connection**: Check DATABASE_URL format
4. **CORS Issues**: Already configured in `api/index.py`

### Debug Commands:
```bash
# Check deployment status
vercel inspect your-deployment-url

# View logs
vercel logs your-app-url

# Test locally with Vercel CLI
vercel dev
```

## 🔄 Continuous Deployment

Once configured, every push to `main` branch will:
1. Automatically trigger deployment
2. Run tests and build
3. Deploy to production
4. Update live site

## 📈 Monitoring

- **Analytics**: Vercel Analytics Dashboard
- **Performance**: Web Vitals in Vercel
- **Errors**: Check Function logs
- **Uptime**: Vercel automatically monitors
